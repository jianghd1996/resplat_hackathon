# A/B 插件实验总表

固定 ReSplat 为赛题提供的代码与预训练权重。模块 A 从训练视角选取前馈输入、建立/读取位姿并规整图像；模块 B 从 ReSplat 导出的标准 PLY 接续训练并输出可渲染 PLY。评测用相同留出视角计算 PSNR、SSIM、VGG-LPIPS；总耗时采用 A + ReSplat + B，渲染/评测耗时另计。不同硬件和“是否复用已建位姿”的时间不能混作同一次实验。下方本机实验表中括号内的 Δ 均为**该行减去同机 10000 步 baseline(A)+baseline(B)**；质量指标和时间都使用同一方向，因此 LPIPS 与耗时的负 Δ 表示改善。历史 4090 表不与本机基线计算 Δ。
