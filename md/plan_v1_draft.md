## 1. 初始维度矩阵

| 模块 / 维度 | 已有实验与机制证据 | 当前真正缺什么 | 可验证的下一假设 | 性能 / 速度预期与风险 |
|---|---|---|---|---|
| A / 视角空间分布 | FPS在bicycle降低中心距离，却降低轨迹覆盖；local全集距离更差 | 内容互补与几何分布的联合约束 | 保留均匀时间分区，仅做有限交换 | 可能改善初始化；距离是约束，不充当质量目标 |

| B / opacity与优化器状态 | 关闭.01重置有效；.8限幅仍无条件清空Adam状态 | 区分参数修改与状态清空的影响 | 对未限幅点保留动量，其他规则不动 | 无需新增渲染，成本低；可能增加遮挡或过拟合，须看留出质量 |
| B / 拓扑与恢复段 | 末步仍分裂/剪枝但不更新；末端剪枝更慢且质量降 | 每次拓扑修改后的恢复曲线 | 先跳过末次事件，再单独试最后20%冻结拓扑 | 可能同时少评分、稳质量；也可能限制必要的新几何 |
| B / 高斯表示与split | 输入全部最短轴在1e-6；long-axis横向方差缩至39.06% | 近薄片初始化下的覆盖/矩守恒算子 | 固定父高斯与随机样本，比较分裂前后图像/alpha/协方差 | 先算子探针；不把标准SfM点配方直接套上来 |
| B / 生长预算与评分成本 | top-k最终点数几乎不变，评分仍全做，反而更慢 | 投影tile/可见点/多视图评分耗时与有效贡献 | 先profile，确认瓶颈后试降低评分频率或有依据的增长预算 | 少点不保证快；不同梯度通道需先归一化 |
| B / 分辨率 | 固定半→全省4.50秒但LPIPS差.0043 | 尺度改变时梯度、半径、采样序列变化 | 固定同视图测单位转换，再做scale-aware调度 | 可能有速度价值；不能同时改阈值、步数、相机序列 |

## 2. 分数据集的追问与检验

**DL3DV：覆盖已经接近饱和，还应继续优化覆盖率吗？** 三主场景点云探针中DL3DV均匀视锥覆盖99.45%，
但它仅反映已生成高斯，可能遗漏未知内容。更值得看冗余和视差；local两视图覆盖更高仍更差。
六场景FOV约96°、路径较平滑，因此均匀骨架应保留；缺轨迹的当前输入默认回退，避免为一个未经验证的指标重建全部SfM。
`0b5635d53b3b…` 的路径比3.98是本地DL3DV中较大者，可作为后续几何压力场景。

**HW：billboard能代表其他三个场景吗？** 不能。basketball/trashbin相邻朝向p95约13.6°/13.8°，
明显高于billboard5.6°；trashbin均匀轨迹覆盖最低65.75%。因此把trashbin作为初次扩展压力场景，
再在最终冻结参数后检查basketball/car。测试挑选依据是输入几何，不是窥看未运行的质量结果。

**Mip：是否应该直接增加context数量？** 当前固定ReSplat输入为16视图，先不改变黑盒契约。
已有两交换探针让bicycle轨迹覆盖+4.60个百分点、counter+3.88个百分点，说明既定配额内还有可观测改善空间。
先验证少量互补交换是否转化为初始化/最终质量，再考虑更昂贵的表示。

**新的十个场景是否都应立即训练？** 探针已全部覆盖；完整训练先保留历史三主场景可比性，
再加入上述3个几何压力场景。其余7个作为参数冻结后的场景级保留验证，不用来反复调阈值。
新增场景若要报B/30k，必须补本机同分辨率的经典训练参考；没有参考就填“—”，不能借counter秒数。

## 3. 回到核心指标后的修订

初始矩阵容易把“代理更好”“点数更少”“看起来更合理”当作目标，因此执行前作以下收敛。

| 初始容易采取的做法 | 指标与证据回顾 | 修订后的规则 |
|---|---|---|
| LPIPS权重40，先加VGG训练loss | 现有loss既没降LPIPS，又有RNG混杂和成本 | 先P0隔离；loss降为P2，先做梯度/分辨率探针 |
| 覆盖越高就越好 | local的双视图覆盖提高也能劣化；轨迹本身偏纹理 | A只保留少量受约束交换，并以留出质量与总时间验收 |
| 点数硬上限自然加速 | top-k与控制最终数相近却更慢 | 先测评分与投影工作量，预算从P1降P2 |
| counter跑通即可扩展或宣布成功 | long-axis在counter微增、DL3DV明显失败 | 三主场景都过门槛，再按几何分层扩展；不逐场景挑配置 |
| 所有快一点的配置都淘汰于质量优先方案 | 5000步总时间更低，有真实Pareto价值 | 保留质量路线和速度路线，不能只留一个“总分最好” |
| 小于10%便稳定满时间档 | counter仅1.567秒余量，旧计时无明确CUDA边界 | 重复计时，报告均值/中位数/范围；硬预算100%与10%档分开 |
| 只要过v0的−.5 dB/+ .01门槛就继续 | 相对当前最佳这可能是显著倒退 | 新候选同时报告相对原基线与no_reset控制，设更敏感的工程门槛 |
| B更快即可接近端到端30秒 | A+ReSplat均值已77.20秒 | 加入A的冷运行成本拆解；不隐藏准备/缓存成本 |

权重20/20/40/20不是原始PSNR、SSIM、LPIPS、秒数的线性加权系数。
缺少官方归一化公式时，仅报告原始指标、逐场景Δ、LPIPS相对变化与时间比，并展示Pareto取舍。
所有接受/停止阈值均为实验预算管理规则，不宣称是官方排名规则。

## 4. 从草案到第一组实验

先做P0可重复性/计时与末步快照；B最先隔离末次拓扑事件、恢复段和opacity动量；
A最先把已经通过全集离线约束的两交换候选接入。前三个B变化保持独立文件和独立对照，不捆绑成新的“万能short_budget”。
只有单项真实有效才组合；核算完整A→ReSplat→B成本。
